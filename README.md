# Simple Linear Regression

This repository demonstrates the basics of **Simple Linear Regression** using Python.  
It covers how to build, train, and evaluate a regression model step by step with a practical dataset.

---

## 📂 Files in this Repository

- **Simple Linear Regression.ipynb**  
  A Jupyter Notebook that explains and implements simple linear regression using the `height-weight.csv` dataset.  
  It includes:
  - Importing and understanding the dataset
  - Data visualization (scatter plots, regression line)
  - Splitting the dataset into training and testing sets
  - Standardization when features have different scales
  - Training a linear regression model
  - Making predictions
  - Evaluating the model with metrics
 

- **height-weight.csv**  
  A sample dataset containing two columns:  
  - `Height`   
  - `Weight`
